Sync across devices

Keeps your log in a file in a GitHub repo, so your phone and your computer stay in step.
Use data. Keeping the log off main means saving a check-in does not rebuild the site.
The token stays on this device. It is never committed and never included in a backup file.

Make a fine-grained personal access token on GitHub, limited to this one repository, with Contents: read and write. Enter it once on each device you use.

This repo is public. Sync writes your whole log to it — including tests that are not on your public page. The Share toggle controls what the page shows, not what the file contains, so treat anything you sync here as readable by anyone.
